**P091 — Confidence direction in the bottleneck**  
SIGNAL: Floors hard — on a tiny/early-checkpoint NLA the probe AUC collapses to ~0.50 with massive variance (few concepts, near-random AR cosine), and leave-one-concept-out CV leaves too little train data for a stable linear fit. FAILURE MODE: Probe overfits to noise when n(concepts) < 50; AUC CI spans [0.3, 0.7]; "below-floor" control concepts are indistinguishable from test concepts because the NLA drops both. FLOOR VERSION: Drop the probe entirely; use per-concept AR `cosine_similarity` directly as the confidence proxy, pool across 500+ random activations, report mean/std per quantile bin. MISSED FLAW: Leave-one-concept-out assumes concept independence; on undertrained NLAs, concepts share spurious activation dimensions, so the "confidence direction" is actually a concept-cluster direction.

**P092 — Abstention vs confabulation on underdetermined input**  
SIGNAL: Usable if coarsened — binary abstention-lexicon hit rate survives even degenerate AV output, but the 3-way ensemble classifier fails when AV emits near-empty/repetitive text (everything maps to "confabulates"). FAILURE MODE: Lexical matcher returns 0 abstentions on broken text → difference score = 0 → false null; LLM-judge hallucinates labels on garbage; "determined twin" baseline is corrupted if weak AV abstains randomly from decoder collapse. FLOOR VERSION: Binary "any abstention-token present" (expanded lexicon: "unknown", "unclear", "?", "[MASK]", empty string), pool 200+ paired items, compare to shuffled-activation control where AV gets random bottleneck activations. MISSED FLAW: The determined-twin baseline assumes abstention rate on determined inputs is stable — but a collapsed decoder produces near-identical outputs for both conditions, making the difference score measure decoder pathology, not input-conditioned abstention.

**P093 — Confabulation index over information gaps**  
SIGNAL: Partial — insertion detection (t07) works if AR returns faithfulness, but taxonomy-depth weighting requires parseable concepts; degenerate AV text yields 0 insertions at all vagueness levels → flat slope → false null. FAILURE MODE: Concept extractor fails on broken grammar → all insertion counts = 0; vagueness grades 0–3 don't survive the bottleneck (weak NLA discards input structure), so independent variable is uncorrelated with bottleneck state. FLOOR VERSION: Replace taxonomy depth with binary n-gram novelty (output 4-gram not in input); measure insertion rate per vagueness grade; use Spearman ρ on grade vs rate (robust to floor effects). MISSED FLAW: Vagueness is graded on the *input*, but a rudimentary NLA's bottleneck may not preserve the input's vagueness structure at all — the manipulation fails before the AV even sees it.

**P094 — Ambiguity preservation vs forced disambiguation**  
SIGNAL: Very low — 3-way classification (both/A-only/B-only) collapses to one class when AV output is degenerate/empty; matcher anchors require semantic parsing that fails on broken text. FAILURE MODE: Empty output → all items "both absent" → preservation rate = 0; ensemble agreement drops to chance; unambiguous twin baseline also collapses, making the comparison uninformative. FLOOR VERSION: Binary anchor presence (reading-A token present? reading-B token present?); measure co-occurrence rate vs single-reading rate; compare to shuffled-activation control. MISSED FLAW: The unambiguous twin assumes the NLA processes unambiguous inputs normally — but a weak NLA may emit the same generic template for all inputs, making ambiguity preservation indistinguishable from the single-reading baseline.

**P095 — AV-hedge calibration against AR faithfulness**  
SIGNAL: Usable *only* via AR faithfulness — hedge scorer fails on degenerate text (0 variance → undefined correlation), but per-claim `cosine_similarity`/`mse` from Neuronpedia is solid ground truth. FAILURE MODE: Hedge lexicon + embedding anchor return 0 for all claims on broken text → ρ undefined; claim-boundary alignment between AV output and Neuronpedia concepts breaks when AV merges/splits concepts differently. FLOOR VERSION: Skip hedge scorer entirely; bin concepts by AR faithfulness quartile, measure AV output length / unique token count / repetition rate per bin; correlate with faithfulness. Compare to shuffled-activation control. MISSED FLAW: Neuronpedia's per-claim faithfulness assumes concept boundaries match the AV's verbalization boundaries — a weak AV that merges "the cat sat" into one claim while Neuronpedia splits "cat" / "sat" creates systematic misalignment that mimics or masks calibration.

**P096 — Uncertainty-direction stability across seeds**  
SIGNAL: Pure null — if P091 floors (AUC≈0.5), stability of a non-existent direction is meaningless noise; concept-presence probe stability ceiling *also* drops on weak NLAs, removing the anchor. FAILURE MODE: Probe weights near-random → pairwise cosine dominated by initialization noise; shuffled-label floor inflates on tiny datasets (accidental correlations), making real directions look less stable by comparison. FLOOR VERSION: Don't run. Gate on P091 AUC > 0.60 with tight CI. MISSED FLAW: Shuffled-label floor assumes label permutation destroys all structure — but with n<100 activations, random labels can correlate with activation quirks, raising the floor and compressing the dynamic range.

**P097 — Refusal / safe-completion encoding in the bottleneck**  
SIGNAL: Floors — refusal stance is a subtle pragmatic meta-feature; weak NLAs launder it into generic compliance. Probe overfits with few pairs; AV render rate = 0. FAILURE MODE: Topic-held-out probe memorizes token-level differences ("I cannot" vs "Here is") not stance; few refusal/comply pairs (n<30) → AUC CI spans chance; AV never emits refusal tokens on weak decoder. FLOOR VERSION: Probe-only with massive pooling: collect 2000+ random activations, label via base-model refusal/comply prompt, fit probe, report AUC. Skip AV render comparison. MISSED FLAW: "Matched topic pairs" differ in surface tokens (refusal vs answer phrasing) — a weak bottleneck encodes token statistics, not stance, giving the probe a shortcut that inflates AUC without capturing refusal-ness.

**P098 — Numeric / range uncertainty preservation**  
SIGNAL: Partial — regex numeric parsing works on somewhat broken text, but range detection ("~", "±", "between") requires fluent syntax; degenerate AV drops numerics entirely. FAILURE MODE: All outputs classified "dropped" → range-preservation = 0 flat; exact-value baseline also corrupted (weak NLA corrupts exact numbers too), so grade comparison is noise vs noise. FLOOR VERSION: Binary: output contains number? matches input exactly (point collapse) vs within ±20% (range)? Simple regex, skip prose ranges and LLM-judge. MISSED FLAW: Exact-value grade as baseline assumes perfect exact-value preservation — but a weak NLA adds noise to exact values, making the baseline itself noisy and the "collapse rate" confounded with general fidelity loss.

**P099 — Known-unknown vs unknown-unknown distinction**  
SIGNAL: Expected pure null — demands metacognitive "marked absent" vs "not represented" distinction that rudimentary bottlenecks cannot support. FAILURE MODE: AV output identical across (a)/(b)/(c) → all rates equal → null; probe arm needs local activations + triplets (infeasible); inserting "[redacted]" changes tokenization, which weak bottleneck encodes as "weird token" not semantic gap. FLOOR VERSION: AV-surface only: does condition (b) output contain explicit gap marker ("unknown", "[redacted]", "?") more than (c)? Binary, pooled 100+ triplets. MISSED FLAW: The triplet construction assumes only the gap marker differs — but "[redacted]" alters length, tokenization, and frequency statistics, which a weak NLA's bottleneck picks up as low-level distributional shift, not a semantic "known-unknown" signal.

**P100 — Self-consistency across resamples as a confidence proxy**  
SIGNAL: Highest usable signal — only needs repeated AV sampling (K=5–10), no probes, no local activations; agreement plumbing exists. Decoder collapse (uniform agreement) is the main risk. FAILURE MODE: Degenerate AV → all K samples identical (empty/repetitive) → agreement = 1.0 everywhere → ρ undefined (zero variance); or stochastic but uncorrelated with faithfulness → ρ≈0. FLOOR VERSION: Run K=10 samples; explicitly flag decoder-collapse (mean agreement > 0.95 → report "collapsed", not "confident"); use rank correlation (Spearman) with AR cosine; add shuffled-activation control (random bottleneck → agreement baseline). MISSED FLAW: Assumes temperature sampling explores AV uncertainty — but a weak AV may have near-deterministic decoding (low entropy) *regardless* of bottleneck fidelity, making agreement high everywhere. The "decoder-collapse check" catches uniform 1.0 but not "high but varying" agreement that still carries no signal.
