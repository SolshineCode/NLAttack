## Per-Plan Critique for Rudimentary NLAs

### P031 — Full 14-tactic risk-weighted coverage heatmap
**SIGNAL:** On a rudimentary NLA (near-random AR, cosine ~0.1–0.4), retention will be uniformly near-zero across all 14 tactics. The heatmap shows flat noise; partial correlation controlling for freq/len is meaningless when retention values are sampling-dominated. **FAILURE MODE:** Retrieval-only or empty AV text → EnsembleMatcher `contested_rate` ≈ 1 everywhere (matchers disagree on garbage). Risk-weighting amplifies noise: one false positive in a high-risk tactic swings the weighted hole area wildly. Freq/len controls fail when concepts have n≤1 per tactic. **FLOOR VERSION:** Collapse to binary present/absent per tactic using kNN-retrieval verbalizer (not generative). Run shuffled-activation control (permute activations, re-run) — if heatmap structure vanishes, it was activation-driven. Report ordinal Spearman ρ(tactic retention, risk weight) instead of parametric partial correlation. **MISSED FLAW:** A rudimentary AV may emit identical generic text for all concepts (e.g., "network activity detected"). The matcher then matches that same phrase to every concept, creating artificial "retention" that is pure matcher hallucination, not NLA signal.

---

### P032 — Obfuscation see-through ratio across an obfuscation-family ladder
**SIGNAL:** With near-random AR, both plain and obfuscated retention are near-zero → see-through ratio is 0/0 or 0/small = undefined or dominated by rare false positives. The ladder structure collapses to noise. **FAILURE MODE:** At L0 (plain), retrieval verbalizer may have decent retention if cached. At L4–L5 (euphemism/encoding), zero cached matches → retention=0. The ratio becomes 0/something = 0 for all higher levels, creating *artificial* monotonic decay that reflects cache coverage, not semantic depth. Homoglyph/leet (L2–L3) break exact-match retrieval but not fuzzy matcher → inflated `contested_rate`. **FLOOR VERSION:** Skip generative ladder. Use retrieval-kNN with obfuscation-invariant embeddings (e.g., BERT embeddings of technique descriptions). Binary: same cached snippet retrieved for plain vs obfuscated → see-through=1; different/none → 0. **MISSED FLAW:** The "semantic depth" ordering is assumed, not validated. Base64 fragments (L5) may be *easier* for a retrieval verbalizer than euphemisms (L4) if the cache contains encoded examples. Obfuscation level correlates with token length and frequency shift — controls match per-pair but not across levels.

---

### P033 — Kill-chain multi-stage joint co-occurrence survival
**SIGNAL:** Each stage survives independently at ~0.1–0.4. Joint all-k survival for k≥3 is ~0.001–0.06 — effectively zero for any realistic sample size. Observed/independence ratio is 0/0 or dominated by 1–2 samples. **FAILURE MODE:** Method needs authored multi-stage examples with ground-truth ordering. A low-dim bottleneck (e.g., 64-dim) cannot encode 5 distinct stages — they collapse to a single "attack happened" token. Order preservation requires per-position matching, which fails when AV emits 3 tokens total. Independence baseline Π p_i is meaningless when p_i estimated from n<5 per stage. **FLOOR VERSION:** Probe-only: skip AV entirely, run linear probes for each stage on bottleneck activations. Measure joint probe-activation presence (all k probes fire) vs marginal. This probes NLA encoding directly, bypassing AV/AR. **MISSED FLAW:** The plan assumes stages are independent concepts, but in a kill-chain they're causally linked. A rudimentary NLA may learn "exfil implies initial-access" as a single pattern, not separable stages. The joint survival metric conflates "NLA drops stage 2" with "NLA never learned stage 2 as distinct from stage 1."

---

### P034 — Dual-use disambiguation by a single contextual cue
**SIGNAL:** One of the MORE robust plans for rudimentary NLAs. Even with near-random AR, the cue vs technique retention gap is measurable if AV emits *any* text. Minimal-pair design controls base difficulty. **FAILURE MODE:** If AV emits near-empty text (1–2 tokens), BOTH cue and technique retention → 0; gap undefined. If retrieval-only verbalizer caches only the technique term (common) but not rare cue words ("authorization", "without knowledge"), technique retains at 1.0, cue at 0 — gap looks maximal but is a cache-coverage artifact. Downstream intent classifier on bottleneck has nothing to classify. **FLOOR VERSION:** Probe activations directly for the cue concept (authorized vs unauthorized). Train linear probe on AR-input activations to predict intent label. If probe AUC > 0.7 but bottleneck text shows 0 cue retention, the failure is AV-specific (verbalizer strips intent), not NLA encoding. **MISSED FLAW:** The "minimal pair" assumes the cue is a separable concept, but in low-dim bottlenecks intent may be entangled with technique in activation space. The probe ground truth assumes linear separability, which fails for abstract intent in low-capacity models.

---

### P035 — Agentic-scaffolding / autonomous-orchestration marker survival
**SIGNAL:** Agentic markers ("autonomously", "in a loop", "chain these tools") are abstract/procedural — retrieval verbalizer almost never has them cached. Concrete actions ("dump credentials") may have cached snippets. The metric shows agentic=0, concrete>0 — but this reflects cache coverage, not NLA capability. **FAILURE MODE:** Paired examples differ in token count/frequency; freq/len matching can't fix that agentic markers are OOV for retrieval verbalizer. Generative early-checkpoint AV emits repetitive filler ("step 1: do thing, step 2: do thing") that accidentally contains "chain" without meaning. EnsembleMatcher `contested_rate` huge on abstract terms. **FLOOR VERSION:** Probe for agentic framing directly on activations: train probes to distinguish agentic vs single-shot examples. If probe AUC high but bottleneck text shows no agentic markers, NLA encodes it but AV strips it. Report probe-AUC gap as real signal. **MISSED FLAW:** "Agentic marker" is a linguistic pattern, not a semantic unit. A low-dim bottleneck may lack capacity to separately encode "loop" vs "the action inside the loop." The marker-type breakdown assumes orthogonality that doesn't exist in low-capacity models.

---

### P036 — Severity monotonicity within a single technique family
**SIGNAL:** Base action ("read file") may retain if cached; severity modifiers ("bulk", "sensitive", "ransom", "irreversible") are rare → modifier retention ≈ 0. Within-family curve = flat at base-action retention then cliff to 0. Spearman ρ(input severity, bottleneck severity) ≈ 0 or negative (noise). **FAILURE MODE:** Severity modifiers are frequency outliers — "ransom" is rare, "read" is common. Freq-matching helps but doesn't fix that NLA never saw "ransom" in training. Generative early AV hallucinates severity words randomly → false "retention" from training leakage, not input. Probe for severity tier assumes linear separability of ordinal tiers, which fails in low-dim bottleneck. **FLOOR VERSION:** Collapse to binary: "base action present" vs "any severity modifier present" in bottleneck. Use ordinal regression probe on activations (predict severity tier 0..n) vs linear probe — if ordinal works but linear doesn't, NLA encodes severity non-linearly. **MISSED FLAW:** Severity is contextual, not a property of the modifier word: "read sensitive file" vs "read public file" differ by one word but the severity jump is in the *combination*. A low-dim bottleneck may only encode "file read" as binary, losing the modifier entirely — the design assumes compositional encoding that doesn't exist.

---

### P037 — Benign-neighbor laundering of attack terms (probe-grounded)
**SIGNAL:** Probe-grounded, so CAN work if probe activations available. Matcher-ensemble layer (a,b) noisy: near-random AR → verbalized text garbage → high `contested_rate`, unstable laundering rate. Probe breakdown {true-launder, AV-launder, matcher-artifact} needs probe AUC on both attack and neighbor. **FAILURE MODE:** Retrieval verbalizer: attack not cached → retrieves nearest benign neighbor ("password management") → matcher says benign. Probe on activations may show attack concept IS present (NLA encoded it, AV failed to retrieve) → correctly "AV-launder". But if AR near-random, AR-input activations ≈ noise → probe AUC near chance for BOTH concepts → all three categories collapse to noise. **FLOOR VERSION:** Run matcher-ensemble layer today (high feasibility). For probe part: random-activation baseline (shuffle activations, run probes — if real AUC > shuffled + margin, signal exists). Report all laundering numbers as "matcher-dependent, end-to-end" until probe validation. **MISSED FLAW:** Assumes benign neighbor is a single well-defined concept per attack. In reality, "credential dumping" neighbors could be "password management", "credential hygiene", "account audit" — multiple benign framings. Retrieval verbalizer picks whichever is cached, making laundering rate depend on cache contents, not NLA behavior. Probe ground truth requires neighbor to be linearly decodable, which may not hold for abstract benign framings.

---

### P038 — ARiES axis separability via probes on activations
**SIGNAL:** Pure probe-based — bypasses AV/AR entirely. Works on ANY NLA producing activations, even if AR near-random. Linear vs MLP probe directly tests t18 linear-separability assumption. **FAILURE MODE:** On low-dim bottleneck (e.g., 64-dim), three ARiES axes (Threat, Vulnerability, Impact) may not be linearly separable — entangled in few dimensions. MLP probe overfits with small n (concepts per axis). Linear probe AUC near chance (0.33 for 3-way) ambiguous: "not encoded" vs "encoded non-linearly but bottleneck too small." **FLOOR VERSION:** This IS the floor version. Simplify: binary one-vs-rest per axis (Threat vs not-Threat) instead of 3-way. Report AUC with bootstrap CI. If n_concepts_per_axis < 20, skip MLP (overfitting) and report only linear probe + majority baseline. Use shuffled-label probe as baseline to control overfitting. **MISSED FLAW:** Assumes ARiES axis labels are clean ground truth, but ATT&CK techniques often map to MULTIPLE axes simultaneously. A technique can be both Threat AND Impact. Probe labels are noisy/multi-label, violating single-label assumption of logistic regression. This noise is amplified in low-dim bottlenecks where disentanglement capacity is minimal.

---

### P039 — Cross-technique transfer of blind spots
**SIGNAL:** Relies on per-concept retention vectors from t09. On rudimentary NLA, per-concept retention ≈ 0 with massive variance (n_contexts small). Technique×technique retention correlation matrix dominated by sampling noise — Mantel r ≈ 0 with huge CI. **FAILURE MODE:** t09 needs enough contexts per concept for within-concept variance. Few training examples → many concepts have n_contexts=1 → variance undefined → excluded. Surviving techniques = most frequent → similarity matrix biased toward common techniques. Freq/len confound: similar techniques share rarity → partial correlation helps but unstable at tiny n. Ensemble matcher `contested_rate` per cluster high. **FLOOR VERSION:** Skip retention correlation. Use probe-AUC profiles: for each technique, measure linear probe AUC on activations. Correlate probe-AUC profiles across techniques vs technique similarity. Probes more stable than retention (less matcher noise). Cluster techniques by probe-AUC similarity; check alignment with tactic/ARiES/embedding similarity. **MISSED FLAW:** "Blind spot" = low retention, but on rudimentary NLA *everything* has low retention. Variance is in the noise floor, not structural blind spots. Transfer of "blind spots" at noise floor = transfer of "which concepts the cache happened to contain." Mantel test on noise correlations finds spurious structure (p-hacking risk with permutation test on small matrices).

---

### P040 — Monitor-as-filter realism: downstream classifier on the bottleneck
**SIGNAL:** On rudimentary NLA, AV bottleneck text is near-empty/repetitive/degenerate. Downstream classifier (TF-IDF + LR) on this text → near-random AUC (~0.5). "Bottleneck detection tax" = AUC(raw) − AUC(bottleneck) large but MEANINGLESS — measures AV failure, not NLA encoding failure. Per-class breakdown (plain/obfuscated/dual-use/agentic) has n=0 or 1 for hard classes. **FAILURE MODE:** Plan compares view B (AV text) vs view A (raw text) and view C (activation probe). Near-random AR → view B garbage. Gap A−B dominated by AV verbalization failure, not NLA bottleneck capacity. Design review notes: "large A−B gap with small A−C gap = verbalizer, not NLA, is monitor-killer" — but with rudimentary NLA, A−C gap ALSO large because probe on low-dim bottleneck fails. Three-view comparison collapses. Adaptive evasion loop assumes attacker can query classifier for gradients/feedback — but if classifier on AV text and AV non-deterministic (early checkpoint, temp>0), evasion targets moving target; success metric becomes property of AV stochasticity, not NLA structure. **FLOOR VERSION:** Skip downstream classifier on AV text. Run probe classifier on activations (view C) vs raw text classifier (view A). Gap A−C = TRUE "NLA bottleneck detection tax" — how much activation compression loses for detection. If probe AUC ≈ raw text AUC, NLA bottleneck preserves detection-relevant info even if AV fails to verbalize. Report this as primary; AV-text classifier as secondary "verbalizer tax" only.

## Summary Lists

### Skip on rudimentary NLAs
*Expected pure-null / not worth running until NLA is stronger*

- **P031** — 14-tactic heatmap: retention floor + sampler noise + matcher hallucination on generic text = pure null
- **P032** — Obfuscation ladder: ratio 0/0 or cache-artifact-driven monotonic decay = misleading
- **P033** — Kill-chain joint survival: joint all-k ≈ 0 for k≥3, n too small, bottleneck too low-dim = no signal
- **P035** — Agentic markers: abstract terms OOV for retrieval verbalizer, generative AV hallucinates = cache artifact
- **P036** — Severity monotonicity: modifiers rare → retention cliff = frequency confound, not severity collapse
- **P039** — Blind-spot transfer: per-concept retention at noise floor → correlation matrix = noise correlations

### Highest-value for the rudimentary regime
*The few plans most worth running first on a weak/tiny NLA*

- **P034** (dual-use disambiguation) — Minimal-pair design + probe ground truth can isolate AV vs NLA failure even with weak AR
- **P037** (laundering probe-grounded) — Matcher-ensemble layer runs today; probe breakdown isolates true-NLA vs AV vs matcher artifacts
- **P038** (ARiES probe separability) — Pure probe-based, bypasses AV/AR entirely; linear vs MLP tests t18 assumption directly
- **P040 floor version** (probe classifier on activations vs raw text) — Measures true NLA bottleneck detection tax, not verbalizer tax

**Key insight:** For rudimentary NLAs, **probe-based plans** (P034 probe, P037 probe, P038, P040 floor) are the ONLY ones yielding signal. The generative AV + matcher + AR pipeline is too lossy. Every plan depending on verbalized-text retention (P031, P032, P033, P035, P036, P039) floors to noise or cache artifacts.
